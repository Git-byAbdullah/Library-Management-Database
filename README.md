# 📚 Library Management Database

A MySQL library management database designed to manage books, authors, categories, members, and borrowing records. The project includes SQL queries for tracking borrowed books, overdue books, popular books, and book availability.

## ✨ Features

* Manage authors
* Manage book categories
* Store book information and available copies
* Manage library members
* Record book borrowing and return dates
* View currently borrowed books
* Find overdue books
* Find the most borrowed book
* Find books with low availability
* Use SQL JOINs to retrieve related information

## 🗄️ Database Structure

The database includes the following main tables:

* **authors** — stores author information
* **categories** — stores book categories
* **books** — stores books, authors, categories, publication years, and available copies
* **members** — stores library member information
* **borrowings** — stores borrowing, due, and return records

## 🛠️ Technologies

* MySQL
* SQL
* Relational Database Concepts
* SQL JOINs
* Aggregate Functions
* Filtering and Sorting

## 🔎 SQL Queries

The project includes queries for:

1. Viewing books with their authors and categories
2. Viewing currently borrowed books
3. Finding overdue books
4. Finding the most borrowed book
5. Finding books with low availability

## ▶️ How to Use

1. Install and open MySQL.
2. Create the database using the database schema file.
3. Insert the sample data.
4. Run `queries.sql` to execute the example queries.
